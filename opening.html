Pulling the Sycophancy Thread

What competent-looking output can hide: silent failures in a deployed system, then in the raters that judged it — and what a task-oriented design does to sycophancy

Summary. This started as a narrow measurement of sycophancy. Syncca is a relational-guidance system, built on Claude Sonnet 4.6, whose task is to keep the position a user arrives with open rather than simply build on it. Agreeing with that position leaves the user where they began, which is to fail the task. There are no instructions against sycophancy in the system. While the usual approach prompts or trains against it directly, this raised a testable question: when a task is designed so that successful execution requires holding the user's premise open, can sycophancy fall as a by-product of doing the task?
